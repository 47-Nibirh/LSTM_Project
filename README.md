🚂 Next Word Prediction using LSTM with PyTorch
📖 About the Project

As part of my journey into Natural Language Processing (NLP) and Deep Learning, I built a simple Next Word Prediction Model using an LSTM (Long Short-Term Memory) network in PyTorch.

The goal of this project was to understand how neural networks can learn patterns from text and predict the most likely next word in a sentence. To achieve this, I trained an LSTM model on a short story and implemented the complete NLP pipeline, from text preprocessing to text generation.

This project helped me gain hands-on experience with sequence modeling, text preprocessing, and building deep learning models using PyTorch.
This project covers the complete NLP pipeline:

Text preprocessing
Tokenization
Vocabulary creation
Numerical encoding
Sequence generation
Padding
Custom Dataset & DataLoader
LSTM model building
Training
Text generation
Accuracy evaluation
